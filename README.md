# The Service and UMC — CRM автосервиса

Внутренняя CRM для автосервиса «The Service and UMC» (Зеленоград): расписание
подъёмников, заказ-наряды, склад, закупки, услуги, клиенты, сотрудники и
финансы (включая счета клиентам) — в одном месте.

Полное описание требований и собранных данных — в [docs/requirements.md](docs/requirements.md).

## Стек

React + Vite + TypeScript + Tailwind CSS v4. Данные хранятся в `localStorage`
браузера (бэкенда пока нет).

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
