# Требования — CRM «The Service and UMC»

## Тип продукта

Внутренняя CRM-система для автосервиса (не публичный сайт-визитка):
расписание подъёмников, заказ-наряды, склад, закупки, финансы и зарплаты
сотрудников — в одном месте, вместо разрозненных таблиц Excel и сторонней
программы для счетов.

## Ключевая боль

Данные сейчас разбросаны: Excel-таблицы у Елены + отдельная программа для
счетов у Юры. Цель — единая система для записи клиентов, заказ-нарядов,
склада, начисления зарплат и выставления счетов.

## Реализовано (MVP)

Стек: React + Vite + TypeScript + Tailwind CSS v4, данные хранятся в
`localStorage` (без бэкенда на этом этапе).

Разделы:
- **Главная** — KPI дня, загрузка подъёмников, критичные остатки, активные заказ-наряды
- **Расписание** — состояние подъёмников и текущие заказы по каждому
- **Заказ-наряды** — список + карточка (статус-пайплайн, работы, запчасти, оплата)
- **Склад** — остатки, критичные позиции, история движений
- **Закупки** — позиции, требующие заказа
- **Услуги** — прайс-лист по категориям (плейсхолдер, ждём реальные цены)
- **Клиенты** — список клиентов и их авто
- **Сотрудники** — состав, тип расчёта зарплаты
- **Финансы** — выручка/расходы/зарплаты, счета клиентам (замена сторонней программы)
- **Отчёты** — сводные показатели (заглушка, будет расширяться)
